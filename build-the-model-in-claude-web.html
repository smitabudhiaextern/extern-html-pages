A browser-only alternative if Antigravity feels like too much

Read this before you start.

Claude's free version has limits. Your chat window can run out of context mid-build, or you can hit a daily message cap. If that happens, don't panic. Wait for the limit to reset (a few hours), open a new chat, re-upload your latest .xlsx + the 10-K, and pick up where you left off.

Patience is the cost of doing this on free. The upside: no install, no friction, works in any browser.

If you have Claude Pro ($20/mo), none of this is an issue — you get Opus, longer context, and 5× more usage.

Step 02 · Prompt 1

Build the model

I've uploaded [COMPANY]'s 10-K. Build a 3-year historical 3-statement model as a downloadable Excel file called [ticker]-historical-model.xlsx. One sheet per statement (Income Statement, Balance Sheet, Cash Flow). Use SUM formulas for subtotals (gross profit, operating income, net income, total assets, total liabilities, total equity, net change in cash). Don't hardcode anything that should be a formula. Give me the file as a download link when you're done.
What happens: Claude reads the PDF, runs Python in its analysis tool, builds the .xlsx, gives you a download link. Click and save to Desktop.

Step 03 · Prompt 2

Check the model connects

Check that the three statements in the Excel file you just built connect properly. Specifically: (1) Net income on the IS should flow into retained earnings on the BS. (2) Ending cash on the CFS should match the cash line on the BS. (3) Depreciation on the CFS should reconcile with PP&E movement on the BS. (4) Changes in working capital on the CFS should match the change in current assets/liabilities on the BS. For each connection, show me the formula linkages. If any are missing or hardcoded, flag them. Don't fix yet — just report.
Follow-up prompt
Fix the missing linkages in one pass. Every connection should be a formula reference between sheets, not a hardcoded value. Give me the updated file.

Step 04 · Prompt 3

Audit every value against the 10-K

This is the equivalent of Antigravity's two audit passes — collapsed into one thorough prompt since Claude web doesn't have sub-agents.
Now audit the Excel file against the 10-K I uploaded. For every cell that contains a value pulled from the 10-K, verify it matches the source. Also check formula intent — are there any AVERAGE() formulas where SUM() was meant? Any missing absolute references on constants like the tax rate? Any missing IFERROR() on ratios? Produce an audit report with every discrepancy flagged. Don't modify the file yet.
Follow-up prompt
Apply all the fixes from your audit report. Give me the corrected file as a download.
Free Tier

Step 05 · Your Work

Cross-check 5 values yourself

  • Open the .xlsx in Excel.
  • Pick 5 cells at random across the three statements (mix line items and subtotals).
  • Don't pick lines Claude already flagged — pick ones the audit considered "clean." That's the test.
  • Open the 10-K side by side. Verify each value.
AI is consistent at catching its own pattern of slips. If there's a systematic error (wrong year column, segment data instead of consolidated), every AI pass might miss it the same way. Your spot-check is the circuit breaker.
If any cell fails: re-upload the .xlsx, tell Claude what's wrong, ask for a fix.

Step 06 · Final Sanity

Does this make business sense?

Claude has verified structure, values, and formula intent. You spot-checked the result. Now the only question left is the one only you can answer.
  • Revenue trend — does it match your P3 thesis?
  • Margin behavior — expanding or compressing? Does that match competitive position?
  • CFO vs net income — what's the gap telling you?
  • Balance sheet shape — debt? Working capital? Inventory?
If something looks off — either the model has an error, or your P3 story missed something. Both are useful discoveries.
