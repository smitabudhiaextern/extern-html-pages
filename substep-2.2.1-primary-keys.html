Give every row one permanent number. That's the primary key.

Two rules a key must follow

Unique, and stable.

Unique

No two rows ever share the same key. Pick any value and it lands on exactly one row, every time.

id 3→Pepperoni · Small

Stable

The key never changes, even when the data around it does. Rename the pizza and the link still holds.

id 1Margherita→"Classic Cheese"still id 1
Why a number beats the name: names get renamed, pick up variant suffixes ("Large", "Deluxe"), and collect typos. A number just sits there and stays itself.
