If You're Stuck

These are the problems students run into most often on this task. Find the one that matches what you see on your screen.

What you seeWhat to do
The template opens, but you can't type in it. It says “View only” at the top. That's the shared original, which nobody can edit. Click File → Make a copy. Your copy is saved in your own Google Drive, and you can edit it.
Your link opens a “You need access” page when you test it in a private browser window. The file is still set to Restricted, which means private. Click Share, then under General access choose Anyone with the link and set it to Viewer. Do this for the deck and the notebook.
A cell fails when you run the notebook from the top, often with NameError: name '...' is not defined. That cell needs something from a cell you ran by hand earlier, or from one you deleted. Click Runtime → Restart session and run all, fix the first cell that fails, and run all again until every cell finishes.
SecretNotFoundError: Secret GEMINI_API_KEY does not exist. (or GROQ_API_KEY) Colab can't find your key. Click the key icon in Colab's left sidebar to open Secrets. Add a secret named GEMINI_API_KEY (or GROQ_API_KEY), paste your key as its value and turn on Notebook access. Then restart and run all.
Your API key is typed straight into a cell, in quotes, instead of coming from Secrets. Delete it before you share. Anyone with the link could see and use your key. Add it to Colab Secrets (see the row above) and read it with userdata.get("GEMINI_API_KEY") (or userdata.get("GROQ_API_KEY")). Your secrets stay private to you, even when you share the notebook.
