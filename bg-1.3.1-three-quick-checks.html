So You Remember It: Three Quick Checks

Don't peek. Answer each one in your head first, then open the reveal.

Question 1

What does ORDER BY do to a result?

It sorts the rows. DESC puts the largest values first, ASC (the default) puts the smallest first. It changes the order of the rows, never which rows or how many.
Question 2

Fill in the blanks: the fixed keyword order is SELECT ... FROM ... ____ ... ____ ... ____.

WHERE, then ORDER BY, then LIMIT. You can drop any of those three, but you can never put them in a different order.
Question 3

What would this return?

SELECT product_title, total_sales
FROM shopify_sales
ORDER BY total_sales DESC
LIMIT 3;
The three top-earning products by revenue across the whole catalog (no WHERE, so all 99 are in play): Dwellings of Eldervale 2nd Edition: Standard ($13,323.56), Dwellings of Eldervale - LEGENDARY Upgrade Kit ($12,514.05), and Dwellings of Eldervale - DELUXE Upgrade Kit ($5,014.81).
