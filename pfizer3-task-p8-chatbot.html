If You're Stuck

Errors are normal when you build something this big. Find the message you see in the left column, and try the fix next to it.

What you seeWhat to do
SecretNotFoundError: Secret GEMINI_API_KEY does not exist. (or GROQ_API_KEY), or NotebookAccessErrorOpen the key icon on the left and check there's a secret with exactly that name. Capital letters matter. Turn on the Notebook access switch next to it, then run the cell again.
NameError: name 'doc_store' is not defined (or any NameError)Colab restarted or disconnected and forgot everything you ran. The runtime is the computer running your notebook. Go to Runtime → Run all.
The gradio.live link won't openThe link only works while the STEP 11 cell is running, and for up to 1 week. If you stopped the cell or Colab timed out, run STEP 11 again for a new link.
"Please upload and process a pharmaceutical PDF document first."Upload the PDF and wait until Document Info says Successfully Processed before you ask.
"I couldn't find relevant information to answer your question."The retriever, the part that finds matching chunks, came back empty. Set the Document Type Filter to All, move Chunks to Retrieve up, and check that Document Info shows more than 0 chunks.
The answer starts with Error generating answer: and mentions 429You sent too many questions too fast for the free tier. Wait a minute and ask again, and keep Chunks to Retrieve small.
