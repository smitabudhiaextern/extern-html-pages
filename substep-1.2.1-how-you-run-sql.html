How You'll Run SQL on Your Laptop

The big idea: You don't need a big database server to run SQL. SQLite is a whole database packed into a single file, breaking_games.db, that lives right on your laptop. Zero setup.

How it compares: SQLite is a whole database in a single file on your computer, giving you zero setup, free, professional-grade tooling. This is what we use. MySQL and PostgreSQL are database servers that run as separate processes; they are production tools and overkill for learning. Oracle and SQL Server are enterprise databases that cost real money and are way overkill.

Why SQLite is the right call for us: It is a single file you can email, back up, or version. There is zero install beyond the viewer app. The SQL it speaks is about 95% identical to any other database. Real companies use it; your phone is full of SQLite databases right now.

Career note: The SQL you write here transfers directly. Land a junior analyst role using PostgreSQL, MySQL, BigQuery, or Snowflake and the patterns (SELECT, JOIN, GROUP BY) are universal.
