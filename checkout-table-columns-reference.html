How to read this table

Navy headerMatters for the abandonment analysis. Hover the header to see why.

Gray headerPresent in the table, but not a useful signal for this investigation.

Solid dotAlways populated — repeats identically on every line item of a cart.

Dashed dotFirst row only — set once per cart, on the first line item, blank on every row after that.

A dashed underline in a cell means the field is genuinely blank in the source data for that row — not "N/A," just empty. That blankness is itself the lesson: watch it appear on rows 2+ of a multi-item cart.

shopify_checkouts: all 32 columns, 9 sample rows drawn from 5 real checkout carts. Highlighted columns matter for the abandonment analysis; muted columns are shown for reference only.
The pattern that matters: only name, email, customer_id, customer_name, created_at, vendor, and every lineitem_* field repeat on every row of a cart. Everything else — total, subtotal, shipping, geography, discounts, and the rest — populates once, on the first line item, then goes blank. Deduplicate on name before you aggregate any of the other fields.
