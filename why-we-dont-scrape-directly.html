Why we don't scrape the websites directly

You might expect the workflow to open Wayfair, Amazon, and Walmart and read the products off the page. It doesn't. Click each reason to see what would go wrong.

These retailers have systems that detect and stop bots. Wayfair uses a security service called PerimeterX, Amazon shows CAPTCHAs, and Walmart slows requests down. A simple request from your workflow usually gets blocked.

The way a page is built changes constantly. Code that reads it correctly today can quietly stop working next week, and your workflow would start returning empty results without telling you.
A simple example
Last week, the price sat here:
<span class="price">$129</span>
This week, the site changed it to:
<span class="sale-price">$129</span>
Your code was still looking for price, so it finds nothing and returns 0 products — with no error to warn you.
To collect this data reliably, the "just visit the page" idea quietly turns into a lot of moving parts you'd have to build and keep running.
