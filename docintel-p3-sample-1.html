How Engineers Read Every Word on a Page

Pfizer gets thousands of vendor documents called SDFs (Supporting Documentation Files), like quality certificates. A compliance team has to flag any that are more than 3 to 4 years old. Before an AI can do that, a program must read every word and know where it sits on the page. Learn the five steps a document AI engineer follows, then watch one do it.

Checked against sample-sdf-document.pdf and the walkthrough video · Oct 28, 2026 · [Content owner], Extern + [Pfizer mentor] · Code tested with PyMuPDF 1.26.5

Bounding box: four numbers that draw an invisible rectangle around one word on a page: left, top, right and bottom. They are coordinates, meaning distances measured from the top-left corner of the page.

Learn: five steps

Here are the five steps, each with the one line of code that does it. The code uses PyMuPDF, a Python library (ready-made code you can borrow) for reading PDFs. In code you write import fitz, because fitz is PyMuPDF's old name.

  1. Open the file: doc = fitz.open("sample-sdf-document.pdf")
  2. Check it has a text layer (hidden text a computer can read): page.get_text("text") should not come back empty.
  3. Get every word with its box: page.get_text("words")
  4. Loop over all pages, top to bottom: for page_num in range(doc.page_count) with sort=True
  5. Save the words as a list of dictionaries in a JSON file (a plain text format other programs can read): 
    import json
with open("sdf_words.json", "w") as f:
    json.dump(results, f, indent=2)

Python basics: tuples and unpacking

A tuple is a fixed group of values in round brackets. PyMuPDF gives you each word as a tuple of 8 values. This is the first word on page 3:

(480.0, 22.799999237060547, 524.447998046875, 44.784000396728516, 'Cytiva', 0, 0, 0)

You read one item by its position, counting from 0. So word[4] is the text, 'Cytiva'.

Unpacking gives each value its own name in one line. *_ means "and ignore the rest".

x0, y0, x1, y1, w, *_ = word
print(w)    # Cytiva
Python basics: loops, lists and dictionaries

Python counts from 0, so doc[0] is page 1 and doc[2] is page 3.

A for loop repeats the same code. range(doc.page_count) gives 0, 1, 2, one number per page.

A dictionary holds labelled values in curly brackets. A list holds many items in square brackets, and .append() adds one to the end.

results = []
results.append({"page": 3, "text": "20240315", "bbox": [200, 203, 244, 217]})

An f-string puts a value inside text: f"Total pages: {doc.page_count}" prints Total pages: 3. And json.dump saves your list to a file.

The point (0, 0) is the top-left corner of the page, and y grows as you go down. Each page of this file is 612 wide and 792 tall.

Why words can come out in the wrong order

PyMuPDF gives you words in the order they are stored inside the file, which is not always the order you read them.

On page 2, without sorting, you get "Certificate of Quality" and then the footer from the bottom of the page ("This product is manufactured in compliance with our ISO 9001..."), before the dates near the top.

Add sort=True to get words top to bottom, left to right:

page.get_text("words", sort=True)
# 'Certificate', 'of', 'Quality', 'Product:', 'ÄKTA™', 'ready', ...

What to do

Steps 1 and 2 get you set up with ready-made code. Steps 3 to 5 are yours to write.

  1. Open the file. Download sample-sdf-document.pdf and open the starter notebook. In Colab, click the folder icon on the left and the upload icon to add the PDF. Then run the first cell: it installs PyMuPDF and opens the file.

  3. Get every word on page 3 with its box, using page.get_text("words").
