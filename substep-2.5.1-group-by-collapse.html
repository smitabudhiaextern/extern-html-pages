Step 5 · GROUP BY

GROUP BY collapses rows into answers.

A plain query hands you back every single row. But Mike doesn't want 99 rows — he wants one number per category. GROUP BY is the operator that folds all the rows sharing a value into a single summary row.

The GROUP BY Collapse Machine — text version

GROUP BY collapses every row that shares a value into one summary row per group. A plain query returns every row; GROUP BY returns one row per distinct value.

Pizza round

Tony's till logged 8 orders today: Margherita $12, Pepperoni $15, Margherita $12, Hawaiian $14, Pepperoni $15, Margherita $12, Hawaiian $14, Pepperoni $15. Running GROUP BY pizza_type returns 3 rows, because there are 3 distinct pizza types. Margherita: 3 orders, $36. Pepperoni: 3 orders, $45. Hawaiian: 2 orders, $28. COUNT(*) counts how many rows folded into each group; SUM(amount) adds their dollars.

Breaking Games round

An 8-row sample of shopify_sales with product types Game, Game Accessory, and Toy collapses under GROUP BY product_type into 3 type groups, each with its SUM(total_sales). This is exactly how Mike compares categories.

Scale-up question

The full shopify_sales table has 99 rows. GROUP BY product_type returns 6 rows, not 4. It is the count of distinct product_type values, not the row count. On the real (messy) data there are 6 distinct values: Game, Game Accessory, a lowercase game (which counts separately from Game), Toy, Gift, and a blank type shared by 4 rows. So 99 rows collapse to 6 groups.

Recap

  • GROUP BY column: folds every row sharing that value into one group.
  • COUNT(*): how many rows folded into each group.
  • SUM, AVG, MIN, MAX: how to combine the other columns inside each group.
  • Rows out = the number of distinct values, not the row count in.
