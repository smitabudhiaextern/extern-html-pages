Run an Open-Source Model on Your Own Computer

When to use this guide

Do Project 6 in Colab. That is the normal way, and everything in the externship is set up for it.

Use this guide only as a last resort: when Colab will not give you a GPU and you cannot finish Project 6 there.

Before you use this guide, try these first:

  • Try Colab again later. Colab's free GPU time comes back after a while.
  • Use Groq. Groq runs open-source models online, with no setup. See Project 8, on the page "Full RAG Pipeline with Gradio UI", in the box "No GPU? Use a free hosted open-source model."

Running Ollama inside Colab does not help, because it still uses Colab's GPU limits.

Small models make more mistakes. Externs got about 65% right with Phi-2 and about 30% with TinyLlama.

What this is

This guide runs the Project 6 notebook on your own computer instead of in Colab. An open-source model is an AI model anyone can download for free.

What you need

You need macOS 14 or newer, Windows 10 version 22H2 or newer, or Linux, plus 15 GB of free space.

RAM is your computer's short-term memory. Your RAM decides which model fits.

On a Mac

Apple menu, then About This Mac. Read "Memory" and the macOS version.

On Windows

Settings, then System, then About. Read "Installed RAM" and "Version".

A tag is a model's short name. You type it to use the model.

Step 0: Install Python and VS Code

The Python page may say 3.12.10 "has been superseded". Ignore that. It is the right version.

On a Mac

  1. Go to https://www.python.org/downloads/release/python-31210/. In the list of files, click "macOS 64-bit universal2 installer".
  2. Open the file and follow the installer.
  3. Download VS Code from code.visualstudio.com. Open the zip file and move Visual Studio Code into Applications.

On Windows

  1. Go to https://www.python.org/downloads/release/python-31210/. In the list of files, click "Windows installer (64-bit)".
  2. Open the file. Tick "Add python.exe to PATH", then click Install Now.
  3. Download VS Code from code.visualstudio.com. Open the file and follow the installer.

Then, on both: add Python and Jupyter to VS Code

VS Code needs two free add-ons, called extensions, to run a notebook: "Python" and "Jupyter". Both are made by Microsoft.

  1. Open VS Code. On a Mac, it is in your Applications folder. On Windows, click Start and type Visual Studio Code.
  2. Look at the narrow bar of icons down the far left edge of the window.
  3. Click the Extensions icon. It looks like four small squares, with one square slightly apart from the others. A panel opens with a search box at the top.
  4. Click the search box and type Python.
  5. In the results, find the one named "Python" with "Microsoft" written under it. Click it.
  6. Click the blue Install button. It may also install a few helper extensions. That is normal.
  7. Click the search box again, delete "Python" and type Jupyter.
  8. Find the one named "Jupyter" with "Microsoft" written under it. Click it, then click the blue Install button.

You know it worked when the blue Install button is gone on both the "Python" and the "Jupyter" extension.

Step 1: Install Ollama

Ollama is a free app that runs AI models locally. Local means on your own computer.

The download page leads with a command to type, but the steps below use the normal installer instead.

On a Mac

  1. Go to ollama.com/download. Pick the macOS tab and click "Download manually".
  2. Open Ollama.dmg and drag Ollama into Applications.
  3. Open Ollama. If macOS warns you, click Open.
  4. If it asks to install its command line tool, allow it and enter your Mac password.

On Windows

  1. Go to ollama.com/download. Pick the Windows tab and click "Download manually".
  2. Double-click OllamaSetup.exe (about 1.7 GB) and follow the installer.

On Linux: follow ollama.com/download.

If a chat window opens, close it.

You know it worked when http://localhost:11434 shows "Ollama is running".

Troubleshooting

  • "Connection refused" or "failed to connect". Open the Ollama app, or run this in a terminal. Then run the cell again.
    Command
    ollama serve
    If it says "address already in use" (on Windows: "Only one usage of each socket address"), Ollama is already running. Run the cell again.
  • PowerShell says "ollama" is not recognized. Close PowerShell and open it again.
  • A timeout error. In the Ollama(...) line, wait longer, for example request_timeout=600.0. Then run the cell again.
  • Out of memory, or very slow. Close other apps, especially browsers. Or switch to a smaller model, such as phi or tinyllama. Run ollama pull for it and change the tag in the notebook.
  • "Model not found". The full message looks like model "phi" not found, try pulling it first. Run ollama pull with the exact tag, for example ollama pull phi. ollama ls lists your tags. The notebook's tag must match one exactly.
