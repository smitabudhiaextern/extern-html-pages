Desk A · Run before you understandLaptop · 15 m

Install n8n → import the pre-built Moodboard Generator template → pick a sample prompt → click run.

Attempt: execute a working agent with zero theory. First node lights up by minute 8.

First moodboard on screen: minute 12. No API key — first run returns pre-rendered images.

Phone 1 · What did you just run?Phone · 10 m

"Introduction to AI agents" training, now as a reveal: agent vs chatbot, explained through the workflow they executed yesterday.

Reveal answers a question the student actually has.

Phone 2 · The language of promptsPhone · 12 m

Attempt: match 3 prompts to the 3 moodboards they produced. Reveal: subject + style + detail rules. Build: draft their own rug prompt, saved for the next desk session.

Attempt → Reveal → Build, all thumb-sized. Merges both Step 2 trainings.

Desk B · Make it yoursLaptop · 15 m

Swap their drafted prompt into the template. Real generation now needs a key — Hugging Face signup lands here, at peak motivation, as the build step of the APIs training.

Build: their own prompt, their own generated moodboard.

Phone 3 · Ship itPhone · 10 m

Share moodboard to the gallery + short reflection (the existing recap, tightened). Progress bar: Project 1 complete. Open loop: "Next agent tracks real rug trends."

Check: visible progress and a reason to return.

API principle: never put credential setup before the first payoff. Desk A's final node serves pre-rendered images (3 sample prompts, generated once by L&D). Real generation — and the key that powers it — arrives in Desk B, when the student wants their prompt rendered.
