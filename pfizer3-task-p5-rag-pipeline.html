If You're Stuck

Here are the errors students hit most often on this task, and what fixes each one.

What you seeWhat to do
SecretNotFoundError: Secret GEMINI_API_KEY does not exist.Open Secrets (the key icon), add a secret named exactly GEMINI_API_KEY, paste your key as the value, then run STEP 1 again.
NotebookAccessError, or a pop-up asking for accessChoose Grant access, or turn on Notebook access next to your secret. Then run STEP 1 again.
API key not validCopy your key again from Google AI Studio and paste it as the secret's value, with no spaces.
Red ERROR: pip's dependency resolver lines that name google-adk, opentelemetry or jediYou can ignore them and keep going. If a later cell then fails with an ImportError, choose Runtime → Restart session and run all cells again.
asyncio.run() cannot be called from a running event loopSTEP 1 hasn't run, and it's the cell that turns on nest_asyncio. Run STEP 1, then run your cell again.
404 NOT_FOUND and a model that is not foundCheck the model line in STEP 8. It should read GoogleGenAI(model="gemini-3.5-flash-lite").
429 RESOURCE_EXHAUSTEDYour free key hit its limit for the minute. Each prompt makes several calls to Gemini, so wait a minute and run the cell again.
NameError: name 'pdf_path' is not defined, or File ... is not a PDFThe upload didn't happen. Run STEP 3 again and choose sample-sdf-document (Project 5).pdf.
FileNotFoundError: no such fileThe file name in your path doesn't match the upload. The easiest fix is to run STEP 3 again and upload the file there.
Extracted 0 pages with content or Indexed 0 document chunksThe PDF has no text the code can read, which happens with a scanned page. Upload the sample SDF instead.
A FutureWarning about fitz, or a warning about HF_TOKENThese are warnings, not errors. Keep going.
