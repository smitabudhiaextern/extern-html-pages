If You're Stuck (Troubleshooting)

Here are the errors students hit most often on this task, and what fixes each one.

What you seeWhat to do
SecretNotFoundError: Secret GEMINI_API_KEY does not exist., or NotebookAccessError, or a pop-up asking for accessOpen Secrets (the key icon) and check there's a secret named exactly GEMINI_API_KEY, with your key as the value. Turn on Notebook access next to it, or choose Grant access if a pop-up asks. Then run STEP 1 again.
API key not validCopy your key again from Google AI Studio and paste it as the secret's value, with no spaces.
404 NOT_FOUND and a model that is not foundCheck the model line in STEP 8. It should read GoogleGenAI(model="gemini-3.5-flash-lite").
429 RESOURCE_EXHAUSTEDYour free key hit its limit for the minute. Each prompt makes several calls to Gemini, so wait a minute and run the cell again.
NameError: name 'pdf_path' is not defined, File ... is not a PDF, or FileNotFoundError: no such fileThe upload didn't happen, or the file name in your path doesn't match the upload. Run STEP 3 again and choose sample-sdf-document (Project 5).pdf.

Still stuck? Ask Claude to explain, not to fix. Give Claude these four things, so it can see exactly what you see:

  1. A screenshot of the error, or the full error text copied from the cell output.
  2. Your notebook. In Colab, choose File → Download → Download .ipynb and upload that file. Your API key is safe, because it lives in Colab Secrets, not in the notebook. Never paste a key into Claude.
  3. The sample PDF you're using, only if the problem is about the answers.
  4. This task's steps, so Claude knows what you're trying to do. They're at the end of the prompt below, so copying the prompt covers this one.

Attach the files, then paste this prompt. You'll learn what went wrong, so you can fix it yourself.
