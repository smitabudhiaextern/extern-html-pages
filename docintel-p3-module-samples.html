Five ways to build one module in the new layout

Each sample takes one live module from the Pfizer document processing externship and rebuilds it with the Training and Task screens from the Oct 22 design review. They differ in where Python basics and troubleshooting live. None of them is final.

The module we picked

We picked Project 3, Step 1. It pairs a Training page, "Learn How to Extract Text and Bounding Boxes with PyMuPDF", with a Task page, "Extract & Structure Data from SDFs". The Training walks through about ten small actions in order. It is also where students run their first real code of the project, so it needs both Python basics and help with errors.

What all five fix from the live version

  • The Training now uses the same file as the Task. The live Training practises on a resume, but the Task uses sample-sdf-document.pdf.
  • The sample output now matches the file. The live Task shows a label "Manufacturing Date:" that is not in the PDF. The real label is "Date of Manufacture:", and the words come out one at a time.
  • Students hand in their work once, in a single submit: the sdf_words.json file plus their notebook link. Sam reviews it against a rubric. The live Task splits the work across a Colab link, a Google Doc and a form, and has no rubric.
  • Every output shown is real. We ran the code on the real file with PyMuPDF 1.26.5 on Oct 28, 2026.
  • Students are told how to get the PDF into Colab, how to download their results and how to share their notebook. The live page skips all three.

It keeps all ten small steps. Each has a "You're on track if" check, using the real output where there is one, and an "If you're stuck" box where needed.

Three short pages

An optional Python check, then separate Learn, See and Do pages. Each page is short and does one job.

 Sample 5

Fix it first

Three cells in the starter notebook are broken on purpose, one each in the Task's first three steps. Students fix them as they go, which turns troubleshooting into a graded skill. This sample needs a new starter notebook.
